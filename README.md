# Product Catalog Application

Краткое описание проекта: Современное веб-приложение на Angular - магазин различных товаров.

## 🛠 Технологический стек
*   **Framework:** Angular (v17+)
*   **Language:** TypeScript
*   **State Management:** Angular Signals (`signal`, `computed`, `output`)
*   **Styling:** SCSS

## ✨ Ключевой функционал
*   **Мгновенный поиск:** Фильтрация товаров по названию в реальном времени по мере ввода текста.
*   **Реактивность на Signals:** Высокая производительность и точечный пересчет интерфейса благодаря Angular Signals вместо традиционного Zone.js / RxJS для локального состояния.
*   **Архитектура Smart/Dumb компонентов:** Четкое разделение ответственности — фильтр и карточки являются переиспользуемыми UI-компонентами, а главная страница управляет состоянием данных.
