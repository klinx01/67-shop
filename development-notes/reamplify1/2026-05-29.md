Developed a functional AuthService leveraging Angular Signals to natively track the user's isLoggedIn authentication state.

Synced the workspace with the shared dev-sprint-2 branch via git pull.

## Challenges & Solutions
Challenge: Product cards within the CSS Grid had inconsistent heights despite applying height: 100% to the internal .card element.

Solution: Identified that the Angular custom tag <app-product-card> renders as display: inline by default. Resolved this by adding :host { display: block; height: 100%; }, forcing the component host element to occupy the full height provided by the Grid cell.
