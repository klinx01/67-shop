**Development Diary: Sprint 3**
Task/Goal: Implementation of a custom provider and InjectionToken for decoupled architecture and mock data management in the 67 shop project.

**What was done**:

Created a custom InjectionToken (PRODUCTS_DATA) to define a unique DI marker for product data.

Registered a custom provider in app.config.ts using the useValue strategy to bind the token with local mock data (mockProducts).

Refactored ProductService to read application data via Angular's dependency injection system using the inject() function instead of hardcoded file imports.

Integrated the injected data into standard Angular Signals.

**Challenges faced & Solving actions**:

First, it was hard to understand the purpose of Injection token as I have never heard of it before. Even AI assistance was not enough in the beginning. It took me a couple of days to understand the purpose of the technology and where to implement it. Finally, after a couple of days, I was able to implement it in the project for mock data injection. 

**Time spent**: 2 days.
