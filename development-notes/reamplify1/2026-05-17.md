# Date: 2026-05-17

- **What I did:**
  Набросал SCSS стили для сетки товаров с помощью CSS Grid (`grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`) в `app.scss`. Оформил саму карточку товара в `product-card.scss`: добавил тень, скругления, выровнял картинку через `object-fit: cover`. Реализовал отправку товара в корзину через механизм `output()`.

- **Problems:**
  Было сложно визуально представить, как изоляция компонентов работает на практике. Не сразу понял, как метод `onAddToCart()` внутри карточки понимает, какой именно `id` нужно отправить, если код для всех карточек один и тот же. 

- **Solutions (or attempts):**
  Разобрался: Angular для каждого элемента массива из `@for` создает изолированный экземпляр класса `ProductCard`. Когда срабатывает клик `(click)="onAddToCart()"`, вызывается метод конкретной карточки, который обращается к своему собственному сигналу `this.product().id` и выплевывает (`emit`) его наверх. В родительском компоненте `App` поймал это событие через `(addToCart)="handleAddToCart($event)"` и вывел ID в консоль.

  План на Спринт 2: Нужно переходить от моковых данных к полноценному состоянию приложения. Планирую изучить и внедрить NgRx / service, чтобы создать настоящий сервис корзины, куда будут складываться эти ID товаров, и выводить счетчик в шапку сайта.
