**Development Diary: Sprint 4**

Task/Goal: Implementation of a global loading indicator and unit testing for the 67 shop project.

**What was done:**

Created a global LoadingService based on Angular Signals to manage the application's loading state.

Implemented an HTTP interceptor that automatically displays the loading indicator before an HTTP request starts and hides it after the request completes using the finalize() operator.

Developed a reusable Loading component that subscribes to the loading state and displays a loading indicator while requests are in progress.

Integrated the loading functionality into the application's root component to make it available globally.

Wrote more than 15 unit test cases covering services, components, pipes, and form validation. The tests verify component creation, form validation rules, service behavior, navigation logic, and pipe transformations using Angular TestBed and Vitest.

**Challenges faced & Solving actions:**

The most challenging part was understanding how Angular unit testing works, especially configuring TestBed, mocking dependencies such as the Router, and testing Reactive Forms. It also took some time to understand how a loading indicator should be implemented globally through an HTTP interceptor rather than inside individual components. After experimenting with different approaches and writing multiple test cases.
