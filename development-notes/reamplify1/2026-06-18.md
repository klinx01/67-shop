# Date: 2026-06-18

- **What I did:**
Continuing the 3rd sprint of the "67-shop" project, focused on optimization and core template features. I implemented the ChangeDetectionStrategy.OnPush strategy across three major components (Header, Footer, and NotFoundPage) to boost application performance by minimizing unnecessary change detection cycles. Additionally, I created a custom CurrencyFormatPipe to standardize product price display, ensuring consistent formatting with the appropriate currency symbol.

- **Problems:**
The biggest challenge was dealing with the ChangeDetectionStrategy imports, as I initially tried importing it from @angular/compiler instead of @angular/core, which caused build errors. Also, while implementing OnPush, I had to ensure that the template properly reacts to state changes; initially, I wasn't 100% sure if the signals would still trigger updates automatically without manual markForCheck() calls.

- **Solutions (or attempts):**
I corrected the import path to @angular/core, which instantly resolved the compilation errors. I verified that using signals within the component's template correctly triggers updates even in OnPush mode, as Angular tracks these dependencies natively. For the CurrencyFormatPipe, I implemented the PipeTransform interface and added null-check logic to return a safe "0" value, preventing potential UI glitches during asynchronous data loading.

- **Thoughts / plans:**
Moving to OnPush significantly improved my understanding of Angular's rendering cycle—it forces me to write cleaner. The custom pipe proved how useful it is to keep transformation logic out of components. My next focus will be the InjectionToken implementation for API configuration, and after that, I plan to dive into lifecycle hooks of Angular.
