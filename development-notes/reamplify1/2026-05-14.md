# Date: 2026-05-14

- **What I did:**
  Развернули с напарником проект на Angular 19/20 в строгом режиме TypeScript. Создал отдельную ветку для своей задачи — реализация карточки товара `ProductCard` для нашего интернет-магазина "67-shop". Импортировал моковые данные товаров и попробовал зарендерить их через новый синтаксис циклов `@for`.

- **Problems:**
  Столкнулся с ошибкой компиляции `NG8002: Can't bind to 'product' since it isn't a known property of 'app-product-card'`. Сначала подумал, что неправильно импортировал компонент карточки в массив `imports` главного компонента `App`. Оказалось, связь была, но Angular не понимал, что у карточки есть входное свойство.

- **Solutions (or attempts):**
  Полез проверять файл `product-card.ts`. Выяснилось, что при объявлении нового Signal-инпута я забыл поставить круглые скобки в конце: написал `product = input.required<Product>`, а нужно было вызвать функцию: `input.required<Product>()`. После добавления скобок Angular успешно связал данные, и ошибка исчезла. Разметку цикла `@for` перенес из `.ts` файла в `app.html`, чтобы разделять логику и шаблоны.

- **Thoughts / plans:**
  Понял, что сигналы в Angular — это функции, и для их инициализации и чтения всегда нужны скобки `()`. Дальше нужно настроить стили, чтобы карточки не стояли в один кривой ряд.
