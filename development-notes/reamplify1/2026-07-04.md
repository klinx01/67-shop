**Development Diary: Sprint 4**
**What was done:**

Implemented a basic shopping cart functionality, even though it was not required by the assignment. Since the project represents an online shop, I considered a cart to be an essential feature, even in its simplest form. Users can now add products to the cart, update quantities, remove items, and view the total number of selected products.

Made several UI and UX improvements across the application. These included adding navigation back to the home page from the header, updating the styles and positions of buttons, improving the product list layout, refining the shopping cart page, and making other small cosmetic changes to provide a cleaner and more user-friendly interface.

**Challenges faced & Solving actions:**

One of the main challenges was deciding how product data should be managed. At the beginning of the project, a local mock products file was created because the assignment did not specify a data source. As the project grew, it became clear that using an API would be a more scalable and realistic approach. However, most of the application logic had already been built around the injected mock data using an InjectionToken. Migrating to an API will require refactoring parts of the dependency injection setup, including replacing the current InjectionToken provider and updating the related services to consume asynchronous data. The last two days, my teammate Vadim and I have been trying to find the best solution for our project. We are planning to ask the person who will conduct our Sprint #3 interview how this should be implemented correctly.

The dilemma is that we have sprint requirements, and we prioritize completing them. However, during the previous sprint, points were deducted because we "didn't go deep enough." Although we met all the requirements and even added some extra functionality, it was considered insufficient. As a result, we have to not only satisfy the sprint requirements but also implement additional features; otherwise, we won't receive the maximum number of points. 

**Time spent: 4 days.**
